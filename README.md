# StudentHub – Student Registration Form

## 📌 Project Overview

StudentHub is a responsive student registration form built using **HTML, CSS, and JavaScript**.

## ✨ Features

* Student registration form
* Name, email, phone and course fields
* Password & confirm password validation
* Show/Hide password
* Terms & conditions checkbox
* JavaScript form validation
* Error and success messages
* Responsive design
* Basic accessibility support

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
